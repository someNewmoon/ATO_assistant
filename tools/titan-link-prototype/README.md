# 泰坦接合个人战斗面板原型

从仓库根目录运行 `python3 -m http.server 8957 --bind 127.0.0.1`，打开 <http://127.0.0.1:8957/tools/titan-link-prototype/>。使用 `?step=power` 直接查看威力骰，`?view=board` 查看版图版式。[接合姿势](poses.html)和[队伍插画](pilots.html)可直接查看大图。

## 接入方向

- 先在个人战斗面板试接合横幅。英雄、泰坦和怒气、命运、凶险读数在版图与掷骰视图之间保持可见。房主的共享版图、轮次浮窗和队员原有入口继续可用。
- 舱内插画强调人的表情、手部动作与泰坦巨臂的同步。页面底色延续现有浅纸和铜线，深色集中在横幅和骰盘。桌面使用横幅构图，窄屏给人和握柄保留高度。
- [插画索引](../../aibp/images/titan-link/manifest.json)使用战斗室的 `hero.argonaut` 稳定 key。吴京是同一存档下 `oleander` 的显示名。按美术参考机体核对画面时使用 `referenceTitan`，真实战斗中的机体名和数据始终取当前装备。没有专属图、机体画面不合适或插画加载失败时，使用无脸第一人称默认图。先使用一张常驻图，其他姿势供视觉对比。
- 武器、骰盘、部位牌和克拉托斯池在掷骰视图相邻，主按钮保持位置。宣告武器、命中、第一能力时段、部位牌与威力、骇物响应与清池、第二能力时段继续由现有流程控制。威力显示区能区分武器和泰坦的红威力骰来源。
- 原型使用练习房版图快照和预设骰果。接入时使用现有实时版图、骰果、状态与存档，不带入原型的假数据和演示按钮。版图工具、闪避／防御、检定、装备和结束回合等现有操作须回归验证。建议用 390px 和桌面检查标题裁切、焦点、视图切换后的攻击进度及缺图回退。

插画使用本地泰坦面板和英雄头像作为视觉参考。最终生成提示词见 [prompts](prompts/)。
