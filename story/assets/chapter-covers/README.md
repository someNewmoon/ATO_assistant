# 剧情书封面

本目录保存阅读页与投屏共用的章节封面。当前素材覆盖循环一的七组分支冒险。每组先用一张共用封面，具名任务可继承所在组的图。

## 准备后续循环的素材

1. 从官中剧情书核对循环、章节 key、开场段落 key。对照选段界面与原书，留下开场摘要和一条构图说明。
2. 先看开场原书扫描。如果有与场景对应、能独立裁切的插图，记录原书位置和裁切范围。纯正文、选项或信息密集的整页仍通过剧情书的原书入口展示。
3. 缺图时用开场能确认的环境、物件和光线生成原创画面。适度推测用于构图，记录在构图说明里。避开后续剧情结果和有待揭示的人物身份。循环一的完整生成提示词在 [prompts.txt](c1/prompts.txt)。
4. 留一份 16:9 图供投屏。阅读页沿用同一份文件，前端按 `anchor` 裁成浅横幅。把标题与段落号交给 HTML，预览时检查窄屏裁切与叠字区域。
5. 将图片放在 `chapter-covers/<cycle>/`，将元数据补入 [manifest.json](manifest.json)。原书裁图的 `source` 用 `book-crop`，`sourceNote` 填书页或扫描索引 key 与裁切位置。原创图用 `generated`，同时保存提示词。
6. 核对每个路径、尺寸、章节 key、开场段落 key，以及阅读页和投屏的预览。素材变更按独立提交交给本地测试整合。

## 接入约定

- 用当前 `cycle` 和真实 `chapterKey` 查 `cycles[cycle][chapterKey]`，图片地址相对 manifest 所在目录解析。保留 `openingEntryKey` 供预览与人工核对。
- 阅读页标题用实际段落标题。封面按章节 key 查找，分支切换时才换共用底图。投屏用同一章节 key 选择同一份图，延续现有正文与原书图切换。
- 没有封面记录时保留默认样式。原书扫描继续使用已有加载逻辑。摘要和构图说明供审阅与素材维护。
- 预览验收覆盖 390px 阅读页、1280×720 投屏、跨模块切换、缺素材回退和原书扫描切换。

本提交只提供素材与目录，阅读页和投屏接入由本地开发测试整合。
